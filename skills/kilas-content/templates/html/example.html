Jalan baru membuat
agent membuka peta.

SvelteKit · $4,28

Kemungkinan terlalu baru untuk data latih Opus 5.5. Agent membaca panduan migrasinya di setiap build.

Gracile+Lit · $4,65

Agent kurang mengenalnya, lalu meng-clone repo atau membaca source di node_modules.

Angular · $4,97

Tampaknya karena kodenya paling besar: 2.009 baris.

Navigasi resmi tidak menjamin argo murah.

SvelteKit memakai MCP-nya di 5 dari 5 build dan tetap termahal ketiga. MCP Nuxt tidak pernah dipakai, padahal Nuxt paling hemat token.
