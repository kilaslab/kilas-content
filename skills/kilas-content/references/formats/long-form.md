# Long form: blog post, notes, newsletter

The long piece is the hub. It holds the full argument, the sources, and the code; the
social pieces are cuts of it that point back. Where it is published, in which language,
and in what file format is in the brand pack (`brand.md`, section "Long form").

## 1. Structure

- **Title**: a claim, not a topic. "We rewrote our docs and cut support in half" beats
  "Our documentation journey".
- **Excerpt** (1–2 sentences): the claim plus why it matters. It becomes the social
  hook, the meta description, and the newsletter preview.
- **Body**: an opening paragraph that states the result; then 2–4 sections, each with a
  heading that is itself a claim ("Quiet is not the same as clear"); code or data
  where it proves something; a closing section with what to do or what is next.
- **Sources** linked inline; numbers with dates.
- Length: as long as the argument needs. Reading time in the brand's metadata if it has
  one.

## 2. Writing

The same method as everything else (`writing-craft.md`): the five story questions, one
turn, numbers that compare fairly, hedges copied from sources. Language rules for the
brand's long-form language (`language/`). First person plural ("we") only for things
the brand did.

## 3. Cutting it into social pieces

Plan the cuts when the long piece is outlined, not after (`planning.md` section 6):

| Cut | Taken from |
|---|---|
| Carousel | the argument's ladder; the excerpt is the cover's stakes line |
| Single post | the strongest number or quote |
| X thread / LinkedIn post | the section headings as posts, the excerpt as the hook |
| Reels script | the result + one example, 45 s |
| Threads | the opinion in the closing section |

Each cut links back to the long piece, and each says something whole on its own.

## 4. Checklist

- [ ] Title and every heading are claims.
- [ ] Excerpt works as a social hook.
- [ ] Sources linked; numbers dated.
- [ ] Cuts listed in the item's `brief.md` with their dates.
- [ ] File written in the brand's format (`brand.md`), in the brand's long-form language.
